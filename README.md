# 流体小票 · 使用说明

一个**单机版**网页应用（PWA）：拍照/相册识别食谱图片 → 自动提取食材 → 核对生成清单 → 灵动岛边备菜边打勾。

## 三个页面端
| 页面 | 文件 | 功能 |
|------|------|------|
| 识别页面 | `scan.html` | 拍照 / 相册选图，离线 OCR 自动提取食材 |
| 生成页面 | `edit.html` | 核对清单、改数量、增删食材，一键生成 |
| 展示页面 | `show.html` | 灵动岛食材清单，点方框打 ✓ 后整行泡沫消失 |
| 首页 | `index.html` | 统一入口，可继续上次未完成任务，查看历史 |

数据在本机三个页面间流转：识别页 → 生成页 → 展示页，全程无服务器。

## 功能
- 📷 拍照 / 🖼️ 相册选图，离线 OCR 识别文字，自动匹配食材词典（错字/形近字/别名容错）
- ✍️ 也可手动输入/粘贴食材清单
- ✏️ 生成页行内编辑数量、增删食材
- 🌀 灵动岛动效：每行"名称 · 数量 · 方框"，打勾出现泡沫破灭消失动画
- 💾 全部数据存本机（localStorage），历史记录自动保存
- 📱 支持添加到手机主屏幕，离线可用（PWA，网络优先缓存策略）

## 如何运行

> ⚠️ 注意：OCR 引擎与语言包通过浏览器 fetch 加载，**必须通过 http 服务访问**，直接双击打开本地文件（file://）会因浏览器安全限制无法识别图片。

### 方式一：本机快速体验（电脑）
```bash
cd 流体小票
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

### 方式二：手机使用（局域网）
1. 电脑上运行上面命令（保持同一 WiFi）
2. 手机浏览器访问 `http://<电脑IP>:8899`
3. 浏览器菜单 → 「添加到主屏幕」，即可像 APP 一样使用

### 方式三：部署到免费静态托管（长期使用，随时可访问）
将整个 `流体小票` 文件夹上传到任意静态托管（如 GitHub Pages、Netlify、腾讯云 COS / 静态网站托管）。首次联网加载一次后，后续可离线使用。

## 使用步骤
1. **识别**：在「识别页面」点「拍照识别」或「从相册选图」，上传食谱/采购单/手写清单截图
2. **生成**：自动跳转「生成页面」，核对清单、修改数量、删除不需要的项，点「生成流体云」
3. **展示**：进入「展示页面」，灵动岛显示清单，每备好一样点方框打 ✓，整行像泡沫一样消失
4. 可随时通过底部导航或首页在三个页面间切换，中途退出下次可「继续准备」

## 说明
- OCR 识别仅供辅助，请以实际图片文字为准，识别不准时可在生成页手动修改
- 食材词典内置常用食材约 300 种，未收录的可手动输入
- 数据仅存于本机浏览器，不会上传任何服务器
